# Verification patterns

- See also: `../templates/VALIDATION.md`, `../templates/UAT.md`, `../workflows/plan-phase.md`, `../workflows/verify-work.md`.
- Each phase has a goal in ROADMAP; verification checks that the codebase delivers that goal.
- Use REQUIREMENTS.md to derive testable criteria.
- Prefer concrete checks (run command, assert output) over vague "verify it works".
- Fix plans should be atomic and re-executable.
